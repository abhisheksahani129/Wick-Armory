
#Wiks Armory – Weapon Inventory & E-Commerce System

Wiks Armory is a full-stack e-commerce application built to manage and sell weapons online.
The system provides product management, user authentication, shopping cart features, and a complete admin panel for inventory control.

Wiks Armory allows users to browse weapons, add them to a shopping cart, place orders, and manage accounts.
Admins have full control over products, categories, and user activities.
The project is built with modern .NET technologies and follows MVC architecture for clean separation of concerns.

#Features

User Features
	•	User registration & login
	•	Browse products by category
	•	Product detail view
	•	Add to cart / Remove from cart
	•	View cart & total price
	•	Place orders

Admin Features
	•	Admin login with special access
	•	Add / Edit / Delete products
	•	Add / Edit / Delete categories
	•	View all users
	•	View shopping details & orders
	•	Manage inventory

Core Functionalities
	•	Shopping cart with session management
	•	Identity-based authentication
	•	SQL Server integrated with Entity Framework
	•	Database seeding for initial admin + sample products
	•	Search and filter products
	•	Responsive UI

#Tech_Stack_Used

Frontend
